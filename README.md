# Experign — Instrument Index

Ten disposable browser instruments. One HTML file each.
Live index: `index.html` · Tools: `tools/`

## Deploy (GitHub Pages)
1. Push this repo to GitHub (public repo named `experign`).
2. Settings → Pages → Source: **Deploy from a branch** → Branch `main`, folder `/ (root)` → Save.
3. Live in ~1 min at `https://ishanexperign-cpu.github.io/experign/`

## Add a tool
Drop the HTML in `tools/`, add an entry to the `TOOLS` array in `index.html`
(and a matching painter in `PV` for its live preview).
